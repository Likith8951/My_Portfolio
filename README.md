# Likith S N — Portfolio Website

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — responsive styling and visual design
- `script.js` — mobile navigation, active section highlighting and footer year
- `Likith_S_N1(2).pdf` — resume used by the Download Resume links

## Run locally
1. Keep all four files in the same folder.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Before publishing
- Verify the LinkedIn URL is the exact public profile URL you want to share.
- Confirm the resume PDF is the latest version.
- Add project repository/demo links when they are available.
- The contact section uses a `mailto:` link; it opens the visitor's email application.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `likith-portfolio`).
2. Upload these files to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site and use the URL shown in the Pages section.
